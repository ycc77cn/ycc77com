2. 安装和介绍

👑 Boom 简介

  • Boom 是一款基于无头浏览器的 Web 弱口令爆破工具。它具有以下特性：

  • 自动识别网页是否是登录页面

  • 自动识别爆破目标类型：表单/传统认证协议类型(Basic/Digest/NTLM)

  • 自动识别登录相关组件并填充点击

  • 自动判别登录成功与否

  • 支持 URL 批量并发爆破

  • 支持单 URL 并发爆破

  • 多种爆破模式：密码优先和用户名优先

  • WebHook 消息推送

  • 支持验证码组件识别
